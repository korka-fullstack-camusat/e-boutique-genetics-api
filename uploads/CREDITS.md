# Crédits des photos produits

Les photos de `uploads/produits/` proviennent de trois types de sources :

- **Images officielles des fabricants** (Hikvision, HP, Dell, Lenovo, Asus, Acer, Apple,
  Ubiquiti, TP-Link, EZVIZ, Fortinet, Cisco, Nexans) : visuels produits publiés par les
  marques, utilisés pour présenter les produits revendus.
- **Pixabay** (licence Pixabay, usage commercial autorisé sans attribution) : produits
  génériques (câbles, clés USB, souris, connecteurs, coffrets, hub, disque dur, onduleurs…).
- **Wikimedia Commons** :
  - `produit-3.webp` (module SFP) — « X2 vs SFP+ optical transceiver.jpg », domaine public.
  - `produit-72.webp` (ferme-porte) — « Door closer.jpg », domaine public.
  - `produit-55.webp`, `produit-60.webp`, `produit-62.webp` (répéteurs Wi-Fi) —
    « Wifi Range Extender.jpg » par **Kskhh**, licence **CC BY-SA 4.0**
    (https://creativecommons.org/licenses/by-sa/4.0/),
    https://commons.wikimedia.org/wiki/File:Wifi_Range_Extender.jpg —
    image modifiée : ajout d'un bandeau de crédit, redimensionnement.

Les liens d'images d'origine (ancien serveur) sont conservés dans `anciennes-images.json`.
